# Roadmap

Соло-разработка, backend **.NET 10** + frontend Next.js/React, ориентир — 4-5 месяцев
полной занятости до рабочего пилота. KISS: не раздувать этапы инфраструктурой.

## Этап 0 — Подготовка (2-3 недели)
- [ ] Закрыть все пункты из `07_open_questions.md` письменно с маркетингом
- [ ] Консультация юриста по MLM-комплаенсу в РК
- [ ] Финализировать ER-модель БД (`db/schema.sql`)
- [ ] Настроить репозиторий, CI/CD, staging на free-tier (`09_mvp_deployment.md`)
- [ ] Quartz.NET + ASP.NET auth на dashboard (ADR-0004)

## Этап 1 — Ядро: сеть + auth (4-6 недель)
- [ ] Регистрация с реферальным кодом, JWT-аутентификация
- [ ] Модель сети (adjacency list, recursive CTE вверх/вниз)
- [ ] Защита от циклов
- [ ] API дерева для фронта
- [ ] Базовый личный кабинет (просмотр дерева)

## Этап 2 — Bonus Engine (5-7 недель)
- [ ] Direct Bonus
- [ ] Unilevel Bonus (+ логика "активности")
- [ ] Matching Bonus
- [ ] Rank Engine (11 рангов)
- [ ] Leadership Pool (Quartz monthly cron + protected dashboard)
- [ ] Ledger `bonus_transactions`, тестирование расчётов на staging

## Этап 3 — Маркет + платежи (4-6 недель, частично параллельно)
- [ ] Каталог продуктов (3 пакета + доп. товары)
- [ ] Корзина, оформление заказа
- [ ] Интеграция FreedomPay (Result URL, `pg_sig`, идемпотентность)
- [ ] Модуль заявок на вывод средств (ручное подтверждение)

## Этап 4 — Бухучёт + админка (2-3 недели)
- [ ] Таблица проводок + экспорт в Excel/1С
- [ ] Админ-панель: пользователи, ранги, начисления, заказы

## Этап 5 — Безопасность + тестирование (3-4 недели)
- [ ] 2FA для вывода средств
- [ ] Rate limiting / anti-fraud на регистрации
- [ ] Шифрование персональных данных
- [ ] Пентест
- [ ] Нагрузочное тестирование расчёта бонусов (симуляция роста сети)

## Этап 6 — Деплой + стабилизация (2-3 недели)
- [ ] Production deployment (zero-downtime)
- [ ] Мониторинг, алерты, бэкапы
- [ ] Мягкий запуск с ограниченной аудиторией

## После пилота (не сейчас)
- Автоматизация массовых выплат
- Мультивалютность
- Полноценный движок двойной записи в бухучёте
- Мобильное приложение
